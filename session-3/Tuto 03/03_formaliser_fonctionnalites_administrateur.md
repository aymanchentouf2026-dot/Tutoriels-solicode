# Tutoriel 2 — Formaliser les fonctionnalités de l’Administrateur

## Objectif
Formuler les fonctionnalités de manière claire et les organiser par entité.

## Synthèse fonctionnelle

| Acteur | Fonctionnalités |
|---|---|
| Administrateur | **Gestion des articles** |
| Administrateur | Lister les articles |
| Administrateur | Ajouter un article |
| Administrateur | Modifier un article |
| Administrateur | Supprimer un article |
| Administrateur | **Gestion des catégories** |
| Administrateur | Lister les catégories |
| Administrateur | Ajouter une catégorie |
| Administrateur | Modifier une catégorie |
| Administrateur | Supprimer une catégorie |

## Exemple de parcours fonctionnel : ajouter une catégorie

1. **Acteur :** l’administrateur.
2. **Écran de départ :** la page de gestion des catégories.
3. **Action :** cliquer sur « Ajouter une catégorie ».
4. **Résultat attendu :** afficher le formulaire de création d’une catégorie.

## Conclusion
Les fonctionnalités de l’administrateur sont organisées autour de deux entités principales : `ARTICLE` et `CATEGORIE`. Pour chacune, l’administrateur peut lister, ajouter, modifier et supprimer les éléments.
